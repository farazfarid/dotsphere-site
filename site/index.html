Twenty-four states

Nine come from the original. The fifteen marked new exist only in Dotsphere. Click one to try it in the phone.

Same maths as the original

The nine original states are a line-by-line translation of the web engine. The tests load the original's own reference file and check every dot: 72 cases, 70,115 values, all within 1e-4. This page runs on the original engine itself, and it agrees with the Swift package on all 24 states to the sixth decimal.

Fifteen more states

Sonar rings, a radar sweep, a sphere that charges. A comet around a planet, ripples, a classic spinner, a gyroscope. Upload and download, typing dots, a recording pulse, a galaxy, a progress ring, a waving sheet, and a sphere that turns into a cube.

Colour, still depth-shaded

The original is strictly monochrome and stays the default. Tint it with one colour, or let the colour change with depth, from near to far.

For CarPlay, widgets, Live Activities

Where a live view is not possible, render frames to CGImage or an animated UIImage. A crossfade closes the loop seamlessly, even for states that are not periodic.

Tuning built in

dots, dotSize and opts change count, size and single mode values. DotOrbPlayground gives you the sliders you just used, on device, and prints the call.

Native and calm

A plain Canvas in a TimelineView. It pauses off screen, holds a still frame with Reduce Motion, and every orb shares one clock so they stay in phase.

Add it

Swift Package Manager

.package(url: "https://github.com/farazfarid/dotsphere", from: "1.0.0")

or in Xcode: File ▸ Add Package Dependencies…, paste https://github.com/farazfarid/dotsphere

Use it

import Dotsphere

DotOrb(state: .searching, size: 64)

// inline next to text
HStack { DotOrb(state: .working, size: 20); Text("Thinking…") }

// tuned, tinted
DotOrb(state: .connecting, size: 64, color: .blue, speed: 2,
       dots: 2.2, dotSize: 1.2, opts: ["thr": 0.52, "lineW": 1.9])
