Beyond the view

Where a live view can't go.

CarPlay templates, widgets and Live Activities only take images. DotOrbRenderer draws any state to a CGImage or an animated UIImage, with a crossfade that closes the loop so it does not jump. Fabian Faraz Farid built it for the CarPlay voice screen of his navigation app Leadwolf.

Same maths as the original.

Install

Add it in a minute.

Swift Package Manager

.package(url: "https://github.com/farazfarid/dotsphere", from: "1.2.0")

or in Xcode: File ▸ Add Package Dependencies…, paste https://github.com/farazfarid/dotsphere

Use it

import Dotsphere

DotOrb(state: .searching, size: 64)

// inline next to text
HStack { DotOrb(state: .working, size: 20); Text("Thinking…") }

// tuned, tinted
DotOrb(state: .connecting, size: 64, color: .blue, speed: 2,
       dots: 2.2, dotSize: 1.2, opts: ["thr": 0.52, "lineW": 1.9])

Questions

What is Dotsphere?

Dotsphere is an open-source Swift package by Fabian Faraz Farid. It gives SwiftUI apps 48 animated, dotted status orbs for AI, agents and loading states, drawn in pure Swift with no assets and no third-party dependencies.

Is Dotsphere the same as thinking-orbs?

No. Dotsphere is an unofficial Swift port of thinking-orbs by Jakub Antalik. The first nine states are a line-by-line translation of his engine and are checked against his reference file. The other 39 states, the colour palettes, the image renderer and the tuning screen are new in Dotsphere.

Which platforms does it support?

iOS 15, macOS 12, tvOS 15, watchOS 8 and visionOS 1, with Swift 5.9 or newer. The package builds for all five.

Can I use it in CarPlay, widgets or Live Activities?

Yes. Where a live view is not possible, DotOrbRenderer renders any state to a CGImage or an animated UIImage. A crossfade closes the loop so that it does not jump.

Who makes Dotsphere, and under which licence?

Dotsphere is made by Fabian Faraz Farid in Mönchengladbach, Germany. It is MIT licensed. The original thinking-orbs by Jakub Antalik is MIT licensed as well, and both copyright lines are in the LICENSE file.
